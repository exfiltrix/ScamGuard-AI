# ScamGuard AI

ScamGuard AI is a fraud-detection system for suspicious messages, links, files, and legacy listing URLs.

## Main Capabilities
- Telegram bot analysis
- Web and API access
- Quick check and deep AI analysis
- Link legitimacy checks
- Pattern-based scam detection
- User-facing recommendations

## Quick Start
```bash
python -m venv venv
source venv/bin/activate
pip install -r backend/requirements-minimal.txt
./start-simple.sh
./start-bot.sh
```

API: `http://localhost:8000`  
API docs: `http://localhost:8000/docs`
