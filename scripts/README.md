# 📁 Scripts - Утилиты для ScamGuard AI

## Доступные скрипты

### 1. `analyze_logs.py` 📊
**Автоматическая обработка логов бота**

Создаёт красивые отчёты с:
- ✅ Терминальный отчёт с цветами и ASCII art
- ✅ HTML отчёт с графиками
- ✅ Анализ здоровья системы
- ✅ Рекомендации по исправлению ошибок

**Использование:**
```bash
# Анализ логов бота
python scripts/analyze_logs.py logs/bot.log

# Создаёт: logs/bot_report.html
```

---

### 2. `view-logs.sh` 🖥️
**Быстрый запуск анализатора логов**

Удобный shell скрипт с автоматическим определением путей.

**Использование:**
```bash
# Сделать исполняемым (один раз)
chmod +x scripts/view-logs.sh

# Запустить
./scripts/view-logs.sh
```
